# OpenEphys.Miniscope.Gui

OpenEphys.Miniscope.Gui is a [Bonsai](https://bonsai-rx.org/) library containing the Open Ephys
Miniscope V4 GUI, a single-window interface for configuring and acquiring data from a UCLA Miniscope
V4 head-borne miniature microscope, including control of an Open Ephys commutator. It is maintained
by [Open Ephys](https://open-ephys.org/).

## Documentation

Installing the GUI, using it, and building custom workflows with this library are covered in the
[Miniscope Software Guide](https://open-ephys.github.io/miniscope-docs/Software-Guide/index.html).

This site holds the [API reference](xref:OpenEphys.Miniscope.Gui), which lists every public type
in the library.
